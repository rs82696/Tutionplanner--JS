# TuitionPlanner (js + SQLite) — Scholarship Matching

A Javascript + Express + SQLite application that:
- Seeds a scholarship catalog from JSON into SQLite
- Creates student profiles
- Matches students to scholarships using rule-based eligibility checks
- Generates a **mock AI** explanation for the top match
- Provides a static HTML demo UI to exercise the APIs

## Demo UI
Open after starting the server:
- http://localhost:3000
